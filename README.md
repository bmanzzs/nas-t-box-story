# NAS-T-BOX: the story

An animated, narrated walkthrough of building NAS-T-BOX: a home NAS with two passively cooled Tesla V100s, a 3D-printed intake duct, and local LLMs.

**Watch it:** https://bmanzzs.github.io/nas-t-box-story/

- `index.html` is the built page; `src/` holds the scenes, engine and `build.py` that produce it.
- `narration-script.md` is the voice-over script.
- `model/duct_v11.glb` is the printed duct shown in 3D.
